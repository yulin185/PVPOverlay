# PVP对战信息助手

<p align="center">
  <img src="资源/logo_256.png" width="128" alt="PVP对战信息助手 Logo" />
</p>

一款面向《洛克王国世界》**闪耀大赛 PVP 直播**场景的 Windows 桌面悬浮窗工具。
主播在直播对战时，可在屏幕顶部的置顶横条上实时展示双方选手名、6 只精灵
（圆形头像 / 名称 / 系别图标）、本小局魔力值、总比分与比赛名称，所有信息
均可在控制面板动态调整并即时上屏。

> 纯 Python + PySide6 实现，界面采用自绘渐变圆角风格，无边框、透明、置顶、
> 少遮挡，适合叠加在游戏与直播画面之上。

---

## 功能特性

- **顶部悬浮横条**：无边框、半透明、始终置顶，宽度随内容自适应并自动居中，
  不强行铺满屏幕，尽量减少对画面的遮挡。
- **双方完整信息**：左右两侧分别展示选手名与 6 只精灵的圆形头像、名称、系别
  图标，中部展示比赛名称与总比分（格式 `0:0`）。
- **本小局魔力值**：每小局 4 个爱心，失去 1 点魔力（击败一只精灵）对应熄灭
  一个爱心，可手动 ±，支持「新小局魔力回满」。
- **总比分管理**：可直接输入，也可用 `比分 -1 / +1` 快捷调整，支持一键清零。
- **精灵阵亡标记**：每个精灵槽可切换阵亡状态，头像变为灰度压暗 + 暗色圆环 +
  发光红斜杠，名字与系别图标同步变灰；标记阵亡自动联动魔力 -1。
- **阵容预设**：把当前 6 精灵保存为命名预设，一键切换；左右两侧共享同一份
  预设列表，上限 **500** 个，同名自动覆盖。
- **选手名历史**：输入过的选手名自动记忆，下拉即可复用，支持一键清空。
- **外部文件批量管理**：支持 `.xlsx / .txt / .csv` 导入、导出与模板下载，
  可在 Excel / 记事本中批量维护大量比赛预设。
- **全局热键**：`Ctrl + Alt + H` 无论当前在哪个应用都能一键显示 / 隐藏悬浮条。
- **系统托盘**：关闭面板后程序常驻托盘，可从托盘菜单快速显示、隐藏或退出。
- **透明度调节**：30%–100% 实时调节悬浮条透明度。

## 环境要求

- Windows 10 / 11（全局热键与托盘基于 Win32，主要面向 Windows）
- Python 3.10 及以上
- 依赖见 [`requirements.txt`](requirements.txt)：PySide6、openpyxl（Pillow 仅
  在重新生成图标时需要）

---

## 快速开始

```bash
# 1. 克隆或下载本仓库
git clone https://github.com/<你的用户名>/PVP对战信息助手.git
cd PVP对战信息助手

# 2. （建议）创建并激活虚拟环境
python -m venv .venv
.venv\Scripts\activate

# 3. 安装依赖
pip install -r requirements.txt

# 4. 运行
python app.py
```

启动后会同时出现「控制面板」与顶部「悬浮横条」。在控制面板设置选手名、选择
精灵、调整比分与魔力，悬浮条会实时更新。

## 外部文件格式说明

控制面板每个选手区都有 **导入文件 / 导出文件 / 导入模板** 三个按钮。

标准 8 列，表头如下（也兼容无表头、按固定位置解析）：

| 预设名称 | 选手名称 | 精灵1 | 精灵2 | 精灵3 | 精灵4 | 精灵5 | 精灵6 |
| --- | --- | --- | --- | --- | --- | --- | --- |

- 精灵可填写：完整 key、编号（如 `416`）、名称（如 `加尔`）或「编号 + 名称」
  组合，程序会自动匹配并对多形态重名进行消歧；存在歧义时建议使用完整 key。
- 文本文件编码为 UTF-8（兼容带 BOM），分隔符支持逗号或制表符，自动识别。
- 导入采用**合并**方式：同名预设覆盖、新预设追加，文件中的选手名会自动加入
  选手名历史；无法解析的行会在结果弹窗中逐条说明，不会被静默丢弃。
- 不确定格式时，先点「导入模板」生成含示例的模板，照填即可。

## 从源码打包

使用 [PyInstaller](https://pyinstaller.org/) 打包为单文件 exe：

```bash
pip install pyinstaller

# Windows 下 --add-data 使用分号 “;” 分隔
pyinstaller --onefile --windowed --name "PVP对战信息助手" ^
  --icon "资源/logo.ico" --add-data "资源;资源" app.py
```

> Linux / macOS 下 `--add-data` 改用冒号 `:`：
> `--add-data "资源:资源"`。

打包产物位于 `dist/` 目录。`build/`、`dist/` 与生成的 `*.spec` 已在
[`.gitignore`](.gitignore) 中默认忽略。
